Consulta de pedido

Funcionalidad pendiente de backend. Aquí solo se puede recuperar una simulación guardada en esta sesión del navegador.

No existe un sistema real de seguimiento. Los estados operativo (pendiente, confirmado, en preparación, enviado, entregado, cancelado) se definirán cuando haya API y base de datos.

Futura API: GET /api/pedidos/{id} con autenticación o token de consulta.
